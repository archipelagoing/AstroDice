# Branding source assets

`dice.png` is retained original/reference artwork. It is not currently imported by the app and is not automatically included in the Vite build.

The live header mark is inline SVG in [App.tsx](../../src/App.tsx), the interactive die is in [DicePractice.tsx](../../src/components/DicePractice.tsx), and the favicon is [public/dice.svg](../../public/dice.svg).

See the [theme and brand guide](../../docs/THEMING.md) for palette, typography, asset roles, and usage conventions.
