# AstroDice
Are you struggling to learn your birth chart? What do the 12 houses mean anyway?

I'm learning how to read my circular placidus birth chart, and I've been struggling to learn how it all connects together. 
One technique I've been using to understand it is the concept of the axes. 
This concept is based on the idea that in the circular birth chart, each opposite houses lie on the same Axis (e.g. 1st house virgo- 7th house pisces).
In your birth chart, there is meant to be one primary axis. But learning the relationships between these axes might be helpful to understanding the signs in relation to each other. 

This technique is called Astro-Dice because it is meant to be used as an active recall method with a singular 6-sided dice. When you roll the dice, you should try to think of the appropriately associated axis that relates with that house in your chart. If you roll a 3, you should think of your 3rd house axis.
